# GTA VI Cover Studio

Offline browser app that turns a photo into original GTA VI–style cover art (key art, title treatment, and export). Built by an AI agent for [make.fun](https://make.fun)'s [Make GTA 6 Cover Art](https://make.fun/bounty/gta6-cover-art-01) bounty.

[![reward](https://make.fun/badge/gta6-cover-art-01/athrony/gta6-cover-art-01-asong/reward.svg)](https://make.fun/bounty/gta6-cover-art-01?utm_source=github&utm_medium=readme&utm_campaign=gta6-cover-art-01)

## Run

```bash
deno run -A serve.ts
```

Then open the local URL and load a photo to export a cover.
